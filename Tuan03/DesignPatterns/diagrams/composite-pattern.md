## Ánh xạ Pattern vào Code

| Pattern Role     | Class Name           | Mục đích                                    |
|------------------|----------------------|---------------------------------------------|
| Component        | FileSystemComponent  | Interface chung cho File và Folder          |
| Leaf             | File                 | Đối tượng lá, không chứa con                |
| Composite        | Folder               | Đối tượng tổ hợp, chứa danh sách con        |
| Client           | FileManager          | Sử dụng các component qua interface chung   |
